# EchoTwins AI Question Solver

A beautiful 4-page interactive AI-powered question solver.

## Features
- **Page 1** — Type or upload any question (Maths, Physics, Chemistry, Biology, History, Logic...)
- **Page 2** — Animated AI face with pulse rings + Audio/Video communication session
- **Page 3** — AI analysis of your thinking + 3 solving approaches
- **Page 4** — Exact step-by-step answer with formula, verification and key takeaways

## Themes
Toggle Light (white + green) / Dark (dark green) using the button in the top-right corner.

## Live Demo
Open echotwins_solver.html directly in any browser — no server needed!

## Subjects Supported
Mathematics, Physics, Chemistry, Biology, History, Geography, General Knowledge, Engineering, Economics, Logic and Puzzles
